# Changelog

## v1.5.0 - AI-generated fork update

This release continues the original work by zulc22 and is maintained in the suerion fork.

The v1.5.0 changes were primarily generated by OpenAI ChatGPT and reviewed and tested by the repository maintainer.

### Added
- Independent selection for Counter-Strike: Source and Team Fortress 2.
- Approximate download and installed sizes in the installer selection prompts.
- Central content-pack definitions for supported Valve games.
- Persistent content storage under `GarrysMod/garrysmod/content_mounts/`.
- Safe automatic updates to `GarrysMod/garrysmod/cfg/mount.cfg`.
- Safe automatic updates to `GarrysMod/garrysmod/cfg/mountdepots.txt`.
- One-time backups of existing mount configuration files.
- Reuse and validation of already installed content.
- Automatic SteamCMD initialization and retry handling for first-run self-updates/cache setup.
- Automated tests for content-pack definitions and mount configuration handling.
- GitHub Actions Windows build workflow with Node.js 22, tests and build artifacts.
- Console pause after success or failure so results remain visible.

### Changed
- Version updated from 1.4.0 to 1.5.0.
- Project identity changed from a CSS-only installer to Garry's Mod Content Installer Plus.
- Console branding changed from `CSSTI+` to `GMCI+`.
- Build output renamed to `gmod-content-installer-plus.exe`.
- Counter-Strike: Source content now uses Garry's Mod's mount system instead of extracting/copying VPK content into an addon.
- Team Fortress 2 uses the same mount-based workflow.
- SteamCMD calls preserve paths containing spaces and validate successful completion.
- Existing unrelated `mount.cfg` and `mountdepots.txt` entries are preserved.
- Windows CRLF configuration files are preserved when updated.
- Malformed existing mount configuration files are backed up and left unchanged instead of being overwritten.

### Removed
- Obsolete VPK extraction workflow used by the original CSS-only implementation.

### Supported content
- Counter-Strike: Source — SteamCMD app 232330 — mounted as `cstrike`.
- Team Fortress 2 — SteamCMD app 232250 — mounted as `tf`.

### Validation
The release workflow was tested with fresh downloads and with already-installed content. Garry's Mod's `path` output confirmed simultaneous CSS and TF2 mounts, including their VPKs and game directories.
