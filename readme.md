# Garry's Mod Content Installer Plus (v1.5.0)

A Windows utility that downloads supported Valve game content directly through SteamCMD and mounts it into Garry's Mod.

> **v1.5.0 is an AI-generated fork update.**
> The v1.5.0 changes were primarily generated by OpenAI ChatGPT and reviewed and tested by the repository maintainer.

Original project by **zulc22**: CSS Texture Installer Plus.  
This fork keeps the original GPL-3.0-or-later license and attribution.

## Supported content

- Counter-Strike: Source
  - Approx. 1.13 GiB download
  - Approx. 2.35 GiB installed
- Team Fortress 2
  - Approx. 9.70 GiB download
  - Approx. 13.99 GiB installed

Sizes are approximate and may change when Valve updates the dedicated-server content.

Each content pack can be selected independently when the installer starts.

## How it works

1. The installer finds Steam and Garry's Mod.
2. It asks which supported content packs should be installed.
3. Existing content under `GarrysMod/garrysmod/content_mounts/` is checked first.
4. Valid existing content is reused instead of downloaded again.
5. Missing content is downloaded directly from Steam through SteamCMD.
6. SteamCMD first-run self-updates and transient cache initialization are handled automatically.
7. The installer safely updates:
   - `GarrysMod/garrysmod/cfg/mount.cfg`
   - `GarrysMod/garrysmod/cfg/mountdepots.txt`
8. Garry's Mod mounts the original game directories, including VPK files, maps, materials, models, sounds and other resources.

Content is stored below:

`GarrysMod/garrysmod/content_mounts/`

Current game directories:

`content_mounts/css/cstrike`

`content_mounts/tf2/tf`

## Configuration safety

Before changing an existing configuration for the first time, the installer creates one-time backups:

`mount.cfg.cssti-backup`

`mountdepots.txt.cssti-backup`

Existing unrelated mount and depot entries are preserved.

If an existing configuration cannot be parsed safely, the installer keeps the original file unchanged and reports an error instead of overwriting it.

## Tested v1.5.0 workflow

The v1.5.0 Windows build has been tested with both Counter-Strike: Source and Team Fortress 2:

- Fresh SteamCMD download and self-update
- CSS and TF2 SteamCMD downloads
- Reuse of already installed content on later runs
- Automatic `mount.cfg` and `mountdepots.txt` updates
- CSS and TF2 mounted simultaneously in Garry's Mod
- Garry's Mod `path` output confirming both mounted game directories and VPKs

## Building

Requirements:

- Node.js 22
- Windows

Install dependencies:

```
npm ci
```

Run tests:

```
npm test
```

Build the executable:

```
npm run build
```

The executable is created as:

`bin/gmod-content-installer-plus.exe`

GitHub Actions runs tests and builds the Windows executable for the `v1.5.0` and `master` branches and for pull requests targeting `master`.
