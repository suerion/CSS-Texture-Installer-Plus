# Garry's Mod Content Installer Plus (v1.5.2 development)

A Windows utility that downloads supported Valve game content directly through SteamCMD and mounts it into Garry's Mod.

> **This fork is an AI-generated continuation and expansion of the original CSS Texture Installer Plus.**
> The changes in this fork are primarily generated by OpenAI ChatGPT and are reviewed and tested by the repository maintainer.

## Supported content

- Counter-Strike: Source
  - Approx. 1.13 GiB download
  - Approx. 2.35 GiB installed
- Team Fortress 2
  - Approx. 9.70 GiB download
  - Approx. 13.99 GiB installed

Sizes are approximate and may change when Valve updates the dedicated-server content.

Each content pack can be selected independently when the installer starts.

## How it works

1. The installer finds Steam and Garry's Mod.
2. It asks which supported content packs should be installed.
3. Existing content under `GarrysMod/garrysmod/content_mounts/` is detected first.
4. Every selected content pack is then checked through SteamCMD with `app_update ... -validate`, even when local files already exist.
5. SteamCMD downloads updates or repairs missing/corrupt files only when needed.
6. SteamCMD first-run self-updates and transient cache initialization are handled automatically.
7. The installer can recover from stale Team Fortress 2 SteamCMD metadata by backing up and refreshing the local app manifest when repeated update attempts fail.
8. The installer writes a session log containing installer status messages and SteamCMD output to help diagnose problems.
9. The installer safely updates:
   - `GarrysMod/garrysmod/cfg/mount.cfg`
   - `GarrysMod/garrysmod/cfg/mountdepots.txt`
10. Garry's Mod mounts the original game directories, including VPK files, maps, materials, models, sounds and other resources.

Content is stored below:

`GarrysMod/garrysmod/content_mounts/`

Current game directories:

`content_mounts/css/cstrike`

`content_mounts/tf2/tf`

## Log files

Starting with v1.5.2 development builds, each installer run creates its own log file.

Logs are stored under:

`%LOCALAPPDATA%/GMod-Content-Installer-Plus/logs/`

The installer prints the exact log path when it starts.

The session log includes normal installer status messages as well as SteamCMD output, including retry information, update states, manifest-related errors and metadata recovery actions. This should make troubleshooting easier without having to collect several separate SteamCMD log files.

## Configuration safety

Before changing an existing configuration for the first time, the installer creates one-time backups:

`mount.cfg.cssti-backup`

`mountdepots.txt.cssti-backup`

Existing unrelated mount and depot entries are preserved.

If an existing configuration cannot be parsed safely, the installer keeps the original file unchanged and reports an error instead of overwriting it.

## Tested v1.5.x workflow

The v1.5.x Windows builds are tested with both Counter-Strike: Source and Team Fortress 2:

- Fresh SteamCMD download and self-update
- CSS and TF2 SteamCMD downloads
- Detection of already installed content followed by SteamCMD validation/update checks
- Team Fortress 2 stale-manifest recovery after repeated SteamCMD `state is 0x6` failures
- Automatic `mount.cfg` and `mountdepots.txt` updates
- CSS and TF2 mounted simultaneously in Garry's Mod
- Garry's Mod `path` output confirming both mounted game directories and VPKs
- Enter-to-close behavior after success or failure

## Building

Requirements:

- Node.js 22
- Windows

Install dependencies:

```
npm ci
```

Run tests:

```
npm test
```

Build the executable:

```
npm run build
```

The executable is created as:

`bin/gmod-content-installer-plus.exe`

GitHub Actions runs tests and builds the Windows executable for the active development branches and for pull requests targeting `master`.
